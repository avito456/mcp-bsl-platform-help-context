# План: ОС-зависимый поиск платформы в мастере `install`

Дата: 20.09.2026
Статус: реализовано.

## Цель

Интерактивный `uv run mcp-bsl-context install` ищет установленную платформу
1С в соответствии с текущей ОС:

1. В каталоге установки: mac — `~/Applications/1cv8`, `/Applications/1cv8`,
   `/opt/1cv8`; linux — `/opt/1cv8/x86_64`, `/opt/1cv8`; win —
   `C:/Program Files/1cv8`, `C:/Program Files (x86)/1cv8`.
   Если версии найдены — выводится список версий, пользователь интерактивно
   выбирает нужную; версия пишется в `config.yml` как `platform.version`.
2. Если установленных платформ не найдено — вопрос о каталоге с файлом
   справки `*.hbk` (с валидацией, что в каталоге действительно есть HBK).

Мастер остаётся tty-only; `--yes` / `--non-interactive` не меняются.

## Изменения

### `mcp_bsl_context/installer.py`

- Удаляется `COMMON_PLATFORM_DIRS`.
- `resolve_platform_path` перебирает `_os_platform_candidate_dirs()`
  (ОС-упорядоченный список) вместо жёсткого списка. Единый источник
  ОС-путей.

### `mcp_bsl_context/interactive.py`

- `interact_before_install` — новая последовательность:
  1. явный `--platform-path` — без вопросов (как сейчас);
  2. `resolve_platform_path` (ОС-зависимый): каталог найден И
     `discover_versions()` даёт ≥1 версии → `prompt_version`; если версий нет —
     считать «не найдено» и перейти к п. 4;
  3. auto-резолв не сработал → ОС-скан: по `_os_platform_dir_candidates()`
     (существующие каталоги) ищется первый корень с версиями; найден →
     список версий + `prompt_version`;
  4. нигде не найдено → вопрос о каталоге с `*.hbk`.
- `prompt_platform_path` — формулировка «Укажите каталог с файлом справки
  платформы 1С (*.hbk)»; после ввода валидация через `discover_versions`;
  при пустом результате — предупреждение и повторный вопрос (loop), выход
  по Ctrl-D.
- `prompt_version` — список версий нумерованным списком; принимает номер /
  строку версии / Enter (последняя) / `auto`; `_version_proc` парсит номер.

### `mcp_bsl_context/__main__.py`

- Правок не требуется (wizard-флаги уже есть).

### Тесты

- `tests/test_installer_interactive.py` — патчить ОС-функцию вместо
  `installer.COMMON_PLATFORM_DIRS`.
- Новые: OS-каталог с версиями → список и выбор версии; пустые/отсутствующие

  без HBK; `--yes`/`--non-interactive` без изменений.
- `tests/test_installer_cli.py` — остаются зелёными.
