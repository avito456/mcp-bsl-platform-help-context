## Найденные проблемы

1. **Критический дефект (FAIL) — ИСПРАВЛЕН:** `search` в режиме `keyword` падал
   с «Внутренняя ошибка» при запросе без совпадений (#8, #9) — в блоке
   did-you-mean `server.py` использовалась переменная `re` без соответствующего
   импорта. Добавлен `import re` + серверный регрессионный тест (`tests/
   test_server_search_tool.py`, 3 теста).
2. **Замечание (MINOR) — ИСПРАВЛЕНО:** hybrid-поиск отдавал «Вставить» на 1-й
   позиции вместо «НайтиСтроки» (#7): semantic-движок реранкал свои ANN-
   результаты до слияния с keyword (двойной реранк). Теперь hybrid берёт
   сырую ANN-выборку и реранкает объединённый пул один раз; keyword-движок
   дополнительно получил матчинг словоформ по стему («строку»→«стро») и
   учёт имени типа-владельца. Результат: `ТаблицаЗначений.НайтиСтроки` — топ-3.
3. **Замечание (MINOR) — ИСПРАВЛЕНО:** `search_strict_typing` искал всю фразу
   одной подстрокой (#24): «Массив конструктор» теперь разбивается на слова,
   ранжирование по числу совпавших слов и позиции первого совпадения,
   результат — 13 тем, `arrays` первая.
