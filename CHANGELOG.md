## [Unreleased]

### Добавлено

- **Интерактивная установка (`install`).** На терминале голый
  `uv run mcp-bsl-context install` запускает мастер: определяет ОС и
  предлагает типовой каталог 1С, при нескольких версиях даёт выбрать
  (`Enter` — последняя, свободный ввод, `auto` — не фиксировать) и
  подтверждает запись. Версия пишется в `config.yml` как
  `platform.version`; уточняются только нерешённые автоматически значения.
  Новые флаги: `--platform-version`, `--yes`/`-y`, `--non-interactive`.
  Не-tty (CI/скрипты) — прежнее неинтерактивное поведение.
- **AI-readiness (этап A).** Все сущности API (методы, свойства, типы) получили
  английские имена-алиасы (`name_en`): `ValueTable` → `ТаблицаЗначений`,
  `FindByRef` → `НайтиПоСсылкам`. Поиск и `find_*` матчат по русским и
  английским именам; дедупликация результатов по русскому имени.
- **Поиск «Тип.Метод».** Запросы вида `ТаблицаЗначений.Добавить`,
  `ValueTable.Add`, `СправочникОбъект::ПолучитьСсылку` разбираются на тип и
  член; точное совпадение возвращается первым результатом.
- **Owner-тип в выдаче.** Результаты поиска и `get_member` показывают
  тип-владелец (`ТаблицаЗначений.Добавить`).
- **Автодетект типа в `info`.** Параметр `type_filter` стал необязательным:
  тип элемента определяется автоматически (метод → свойство → тип); при
  неоднозначности возвращаются варианты с подсказкой.
- **Инструмент `health`.** Статус сервера: версия платформы, источник данных,
  статистика контекста и готовность semantic/hybrid.
- **Прогрев семантики.** Флаг `--warmup` / `MCP_BSL_INDEX_WARMUP` /
  `index.warmup: true` загружает модели и готовит индекс при старте без
  пересборки.
- **Did-you-mean.** При пустом результате keyword-поиска возвращаются
  ближайшие по расстоянию редактирования имена (`engine.suggest`).
- **Двуязычные описания инструментов** (RU + EN) и EN-блок в
  SERVER_INSTRUCTIONS.
- **Интеграционные тесты на реальном HBK** и grep-guard, который запрещает
  несуществующие имена API в документации.

### Исправлено

- Убраны выдуманные примеры API (`НайтиПоСсылке`) из инструкций, docstrings и
  README: такие имена не существуют в данных и ломали копируемые запросы.
- Шаблонные имена больше не экранируются бэкслешами: `СправочникОбъект.<Имя
  справочника>` копируется в `info`/`get_member` как есть.
- Авто-fallback: если semantic/hybrid недоступны (модели/индекс),
  `search` возвращает результаты keyword с явной пометкой вместо ошибки.

### Технические детали

- Embed-текст семантического индекса дополнен EN-алиасами; fingerprint индекса
  изменён — пересборка произойдёт автоматически при первом semantic/hybrid
  запросе (или по `--reindex`).
